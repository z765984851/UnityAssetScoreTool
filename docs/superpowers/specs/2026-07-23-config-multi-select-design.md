# 配置选择面板多选设计

## 目标行为

配置中心中原本支持多个配置引用的字段，应允许用户在同一个居中选择面板内一次勾选多项。首批覆盖规则应用项中的“资源类型配置”和“检测配置档”。

打开选择面板时，应展示字段当前的完整选择状态。用户可以切换任意选项，搜索不会丢失未提交的选择。点击“确认”后一次性替换字段内容；点击“取消”或直接关闭面板时，不修改配置工作副本。

## 范围

本次包含：

- 已有规则应用项中的资源类型配置多选。
- 已有规则应用项中的检测配置档多选。
- 新建规则应用项时的资源类型配置多选。
- 新建规则应用项时的检测配置档多选。
- 现有配置选择面板的多选能力，以及配置窗口提供的统一调用入口。

本次不包含：

- 修改单选字段的交互或数据结构。
- 修改 `RuleApplyConfig`、`RuleApplyItem` 的序列化字段。
- 修改规则匹配、扫描、评分或报告逻辑。
- 新增通用选择框架或新的弹窗体系。

## 交互设计

多选模式沿用当前居中的配置选择面板、搜索框、选项列表、取消按钮和确认按钮。

- 打开面板时，字段中已有的有效引用显示为已选择。
- 点击选项行切换该项的临时选择状态，不立即修改工作副本。
- 搜索只过滤可见行，不改变已选择集合。
- 确认按钮始终可用，因为资源类型配置和检测配置档都允许为空。
- 确认后按照选择面板原始选项顺序生成结果，避免选择顺序随搜索和点击顺序变化。
- 结果不包含重复引用。
- 取消或关闭面板时丢弃临时选择。
- 单选模式继续保持现有行为，包括空值选项、确认条件和单个返回值。

## 组件与职责

### `ConfigSelectionPanel`

在现有单选能力上增加显式多选模式。面板负责：

- 保存本次打开时的选择模式。
- 保存多选模式下的临时已选集合。
- 根据模式绘制选中状态并处理行点击。
- 在确认时返回按选项顺序排列的选择结果。
- 在关闭时清理本次回调和临时状态。

单选和多选应使用各自明确的打开入口或参数契约，避免现有单选调用方被隐式改变。

### `ConfigWindow`

保留现有 `ShowSelectionDialog` 单选入口，并增加多选入口。窗口继续负责加载指定配置类型的全部可选项；调用方只提供当前选择和确认回调。

### `RuleApplyConfigPage`

`BuildObjectReferenceArray` 继续负责资源类型和检测配置档的标签展示，但“添加”操作改为打开多选面板，并以当前数组作为初始选择。确认后，通过 `SerializedObject` 在一次 Undo 记录中整体替换数组，随后沿用工作副本变更通知和页面刷新流程。

### `CreateRuleApplyItemPanel`

新建面板仍使用自身的临时 `assetTypes` 和 `profiles` 集合。打开多选面板时传入当前集合；确认后整体替换对应临时集合并刷新列表。只有最终确认新建规则应用项时，才写入 `ConfigWindowData` 管理的工作副本。

## 数据流

已有规则应用项：

1. 从目标数组读取当前引用。
2. 配置窗口构建全部候选配置。
3. 多选面板维护临时选择。
4. 用户确认后返回有序、去重的引用列表。
5. 页面整体替换工作副本中的数组。
6. 发送工作副本变更通知并刷新页面和诊断状态。

新建规则应用项：

1. 从创建面板的临时集合读取当前选择。
2. 多选面板维护并返回新的临时选择。
3. 创建面板替换自身集合并刷新预览。
4. 用户确认创建后，统一写入新规则应用项。

## 边界与错误处理

- 忽略候选项中不存在的初始引用，不在确认结果中制造无效值。
- 空候选列表沿用当前空状态展示，确认后可得到空集合。
- 已选项被搜索过滤时仍保留选择状态。
- 多次打开面板时不得复用上一次的临时选择或回调。
- 面板关闭、取消和确认路径都应清理多选临时状态。
- 不改变 Package 配置只读、工作副本、Undo、Dirty 和统一保存语义。

## 风险

- 扩展公共选择面板时误改现有单选行为。
- 搜索重建列表后临时选择状态丢失。
- 整体替换数组时遗漏 Undo、工作副本变更通知或刷新。
- 新建面板和已有配置编辑使用不同数据源，导致其中一条路径仍只能逐项添加。

## 验证

静态检查：

- 核对单选与多选入口的所有调用方和回调类型。
- 核对多选确认结果的顺序、去重和空集合处理。
- 核对已有编辑路径使用 `SerializedObject`、Undo、变更通知和刷新。
- 核对新建路径只修改创建面板临时状态，最终确认后才写入工作副本。
- 核对新增及修改方法的 XML 职责注释。

Unity 验证：

- `AssetScoreTool.Editor` 编译无错误，Unity Console 无相关编译报错。
- 已有规则应用项可同时增加、取消多个资源类型和检测配置档。
- 新建规则应用项可同时选择多个资源类型和检测配置档。
- 搜索后仍保留被过滤项的选择。
- 确认空选择可清空字段。
- 取消或关闭面板不改变原选择。
- 规则选择、白名单规则选择等现有单选入口行为不变。
