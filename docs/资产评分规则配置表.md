# 资产评分规则配置表

本表汇总当前 Package 版本内置的 81 条资产评分规则。每条规则均具有对应的评分规则配置资产和 Checker 实现，并已在 Package 默认规则应用配置中启用。Package 内置内容只读，使用方可以直接引用，但不能在 Package 中修改。

## 字段说明

| 项目 | 含义 |
| --- | --- |
| 内置规则配置资产名 | Package 中已有的只读规则配置资产名称。 |
| `ruleId` | 规则配置与 Checker 之间使用的唯一标识。当前命名遵循 `basic.<资源类型>.<规则语义><阈值>`；不同阈值和不同平台特性使用独立 ID。 |
| `displayName` | 配置中心和扫描结果中显示的规则名称。 |
| `description` | 规则检测内容、检测口径和触发条件。 |
| `priority` | 规则执行优先级；当前内置规则均为 `0`。 |
| IssueInfo `displayName` | 规则命中后显示的问题名称。 |
| `issueMessage` | 问题影响和修改建议。 |
| `RuleApply.assetTypeConfigs` | Package 默认规则应用配置为该规则关联的资源类型。 |
| `RuleApply.profiles` | Package 默认规则应用配置为该规则关联的检测配置档。 |
| `RuleApply.isEnabled` | Package 默认规则应用配置中的启用状态；当前表内规则均为 `true`。 |
| 问题等级 | 扫描结果中显示的 `Info`、`Warning` 或 `Error` 严重等级。 |

`全部` 表示 Package 默认规则应用配置已为该规则关联 `PC`、`Web`、`Android`、`IOS` 四个 Profile。带阈值的检测已经按表中各行拆分为独立规则和 RuleApplyItem。

表内文本字段的固有名词采用 `English(中文)` 格式；代码标识符、API 名称、`ruleId`、资源资产名及指令（如 `#pragma`）保持原样。

## 当前实现范围

本文所有规则均对应当前 Package 版本中的内置规则配置资产和 Checker 实现，并已在 Package 默认 `RuleApplyConfig_Default` 中启用。使用方保持项目设置中的“当前生效规则应用配置”为空即可使用这份默认配置；需要调整应用范围或白名单时，应把默认规则应用配置“复制到本地”、设置新的唯一 ID，并在项目设置中选择该本地副本。Spine 规则属于可选实现，只有在项目同时提供 `spine-unity` 与 `spine-csharp` 并启用 Spine 检测后才会参与编译和扫描。
